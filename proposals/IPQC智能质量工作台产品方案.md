## <a id="section-summary"></a>__执行摘要__

IPQC 智能质量工作台是面向制造前制程的一体化过程质量检验数字化工作台，以统一口径聚合首件、终检、投诉、点检、培训、绩效六项质量数据，实现"数据一次录入、全厂口径一致、异常自动预警、处置有据可查"。

__覆盖范围__

__聚合指标__

__点检评分__

__异常处置__

6 个责任区

首件 / 终检 / 投诉 / 点检 / 培训 / 绩效

满分 140 分 · 目标 100 分

NG 5 分钟反馈 · 15 分钟介入

## <a id="section-1"></a>__引言：为什么要做这个工作台__

前制程（冲压、注塑、压铸、五金、涂装、印刷）的质量管理长期依赖分散的 Excel 台账：首件检验、终检 FQC、客户投诉、过程点检、人员培训、绩效六类数据各记一本，口径不一、相互割裂。由此带来三个突出问题：

1. __数据不可比__：各车间台账的满分、目标、统计维度不统一，横向对比时"看起来都达标"，实则掩盖了真实差异。
2. __异常靠人盯__：首件 NG、终检不良、投诉未结案等风险散落在台账里，靠检验员与主管人工翻找，反馈滞后。
3. __处置难闭环__：从发现异常到复检结案没有统一的流程约束，容易"报而不改、改而不验"。

IPQC 智能质量工作台把六类数据聚合为__统一的月度目视化看板 \+ 车间子工作台__，用一套口径贯通"数据录入 → 指标汇总 → 异常预警 → 处置闭环"的全过程。

### <a id="section-2-1"></a>__1\.1 产品定位__

面向制造企业前制程质量管理的一体化 __IPQC（过程质量检验）数字化工作台__：以统一口径聚合首件、终检、投诉、点检、培训、绩效六项质量数据，为品质主管提供"一眼看清全厂、一键下钻车间"的目视化看板，为异常处置提供流程化闭环。

__一句话概括：数据一次录入、全厂口径一致、异常自动预警、处置有据可查。__

### <a id="section-3-2"></a>__2\.2 核心使用场景__

1. __月度质量例会__：打开总看板，按"全年 / 单月"切换，展示六项指标的月度走势与车间横向对比，作为汇报与复盘依据。
2. __每日巡检__：进入对应车间子工作台，查看首件合格率、点检得分、投诉结案率，发现未达标项并安排整改。
3. __异常处置__：首件 / 巡检判定 NG 后，按 5 步流程完成反馈、介入、对策、复检、结案，全过程留痕。
4. __改善立项__：通过"重复投诉""高不良率"等预警识别需纳入改善专案的异常，针对性立项。

### <a id="section-5-2"></a>__4\.2 客户投诉闭环流程__

投诉记录按"投诉部门（谁投诉）"与"被投诉车间（谁的责任）"两个维度登记。闭环要点：

1. __登记__：记录投诉的零件、料号、问题描述、投诉来源部门、责任车间、责任人。
2. __归责__：投诉统计以"投诉来源部门"为维度（回答"谁在投诉我们"），而非"被投诉车间"（那永远是自己）。
3. __闭环__：跟踪结案状态与是否按时回复，未结案投诉自动进入预警。

### <a id="section-5-3"></a>__4\.3 终检 FQC 流程__

1. __台账__：每个车间一本独立 FQC 台账（一车间一本，不混用）。
2. __统计__：按不良描述归类，输出批次不良率、柏拉图、不良 TOP。
3. __预警__：单条记录不良率 ≥ 20% 触发"终检高不良"预警；批次不良率 > 3% 触发"终检批次不良率"预警。

### <a id="section-5-4"></a>__4\.4 点检评分与达标流程__

1. __评分制__：全厂同一套评分表，全表满分 __140 分__（基础项扣分 \+ 加分项），目标 __100 分__，6 个责任区同一张表、同一规则。
2. __适用项口径__：注塑毛边责任区承担的项目较少（适用项分值 1–9 月 40 分、10 月起 60 分），因此得分天然偏低——这是"适用项少"，不是"执行差"，__不做任何折算__。
3. __达标判定__：得分按目标 100 分判定达标 / 未达标，按实际得分报告，不折算达标线。
4. __全厂均值双口径__：全厂均值按"含毛边 / 剔除毛边"两种统计范围并列展示（如含毛边 93\.1 分、剔除毛边 104\.1 分），避免低分责任区被平均值"平滑"掩盖。

### <a id="section-5-5"></a>__4\.5 数据流转总览__

## <a id="section-6"></a>__5\. 技术与实现要点__

本章说明工作台的技术架构与关键统计口径。

### <a id="section-6-1"></a>__5\.1 总体架构__

- __纯前端单文件交付__：最终产物为单个 HTML 文件，零第三方依赖、离线可用、双击即可打开，便于车间电脑分发使用。
- __数据链路解耦__：Excel 台账 → 抽取脚本 → __data\.json__ → 构建脚本 → 单文件 HTML。数据更新只需重跑抽取 \+ 构建脚本。

### <a id="section-6-2"></a>__5\.2 前端实现__

- __图表手写 SVG__：柱状图、折线图、柏拉图、环形图、热力矩阵、迷你折线均以原生 SVG 绘制，无图表库依赖，可精确控制样式。
- __标准文档自动查询__：首件巡检页左栏内置标准 / 规范查询面板，索引本地 Excel / Word / CAD 标准文档（扫描脚本 __scan\_std\.py__ 生成 __std\_index\.js__），支持关键词即时过滤、类型 / 分类筛选与一键打开；经 File System Access API 授权后可直接扫描本地标准目录。
- __响应式三档宽度__：适配桌面、笔记本、大屏三档宽度，确保 KPI 卡片与图表不溢出。
- __交互__：全年 / 单月切换、车间下钻、悬停读数、异常跳转。

### <a id="section-6-4"></a>__5\.4 质量保障__

- __自动化测试__：冒烟测试（多宽度 × 多入口，校验 0 报错 / 0 溢出 / 0 空页）\+ 终检回归测试（校验 FQC 数据一致性）。
- __浏览器渲染验证__：改动后经真实浏览器渲染复核，避免模板字符串改动引入的隐性错误。
- __口径说明可追溯__：数据口径说明页集中解释每个数字的统计规则。

### <a id="section-7-2"></a>__6\.2 待明确事项__

1. 是否需要多用户登录与权限分级（如检验员 / 主管 / 管理层不同视图）。
2. 是否需要移动端 / 平板端操作。
3. 数据是否上云，实现多人协作或跨厂区访问。
4. 是否接入 MES / ERP 等系统，实现数据自动同步。
5. 培训模块的完整功能范围（仅记录，还是含考核 / 证书）。
6. 绩效加减分的具体规则明细。
7. 数据导出的目标格式与用途。
