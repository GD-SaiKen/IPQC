## 1. 结论摘要

2026-11-09 基线时，现系统在 **信息架构（9 个视图、6 车间、全部/单车间的导航规则）** 和 **领域 KPI 计算骨架** 上与原型、规格基本一致，已具备可用的 MVP 演示路径（总看板 → 进车间 → 各模块列表）。

基线差距主要集中在：**总看板与车间总览的目视化深度**、**各业务页的区块完整度**、**可编辑表格与导出/撤销交互**、以及 **培训/绩效/点检/FQC/投诉** 等模块的原型级图表与闭环字段。基线页面多为「KPI 卡片 + Element 表格节选」。该批差距已于 2026-11-10 复核中大部分关闭，见 §1.1。

以下「一致」指功能意图或数据口径已对齐；「不一致」指页面缺块、交互不同或仅为占位实现。

### 1.1 2026-11-10 实现后复核

本轮已按规格 §7 与本文第 13 节优先级补齐下列差距；第 2–12 节保留 2026-11-09 的基线快照，不再逐格改写：

- 总看板：月份切换、负责人/培训人次/综合达成列、全厂合计、单元格着色、热力矩阵（7 指标）、投诉与点检走势、异常关注可跳转。
- 车间总览：5 步 NG 流程、终检不良 TOP、绩效 TOP7、预警直达首件 / FQC / 投诉。
- 首件：标准索引（搜索 + 类型 + 分类）、6 项 KPI、全字段可编辑、阶段筛选、NG 确认角色、100394-003 追踪、NG 率与反馈分布。
- FQC：月度柱线图、柏拉图、NG TOP 零件、检验员统计、可编辑 NG 明细与清查表、>3% / ≥20% 预警、CSV。
- 投诉：月度趋势、根因、来源 donut、责任人负荷、完整闭环字段、未结案 / 重复提示。
- 点检：4 KPI、排名 spark、责任区切换、1–10 月趋势、项明细、30 日色块、含/剔除毛边均值。
- 培训：资料 / 实施 / 考核 / 技能矩阵四段，技能 1–4 点击循环。
- 绩效：前三名、A/B/C/D、加减分构成、只读排名、可编辑明细、规则全文（不含工资金额）。
- 数据：数据源清单、口径说明、各表 CSV、JSON 导入覆盖提示、恢复种子两次确认、存储失败提示。
- 跨页编辑：内联编辑、搜索分页、单表 Ctrl/Cmd+Z、Tab/Enter、区域粘贴、保存时间、打印隐藏工具。

仍保留的差异（可接受或不在本期范围）：侧栏模块记录数角标、页面视觉风格、hash 深链、Excel/Word/CAD 仅复制路径、无浏览器 E2E 自动化。

## 3. 总看板（`board`）

### 3.1 一致

- 月份切换：全年 + 1–10 月（`el-radio-group` ↔ 原型 `UI.mon`）。
- 六项 KPI 摘要：首件、终检、投诉结案、点检均值（含剔除毛边提示）、绩效均分、培训人次。
- 车间横向对比表：六项指标 + 行点击进入车间（`@row-click` ↔ `data-enter`）。
- 异常关注：规则与原型 `boardAlerts` 同源思路（`domain/ipqc/kpi.ts`），可点击进车间。
- 注塑毛边首件空值：领域层按「—」处理（表内体现依赖对比表着色，见下）。

### 3.2 不一致

| 原型区块 | 现系统状态 | 影响 |
|---|---|---|
| 页面标题「总看板 · 全车间月度目视化」 | 仅顶栏「总看板」，内容区无同级标题 | 例会投屏识别度弱 |
| 对比表：负责人、培训人次、**综合达成**（x/y）、热力着色单元格、表脚注（毛边/全厂点检均值） | 简化表：无负责人、无培训人次列、无综合达成、无单元格底色 | 横向对比信息量减少 |
| **各车间投诉批次月度走势**（柱状图） | 无 | 规格 P0 目视化缺口 |
| **各车间点检得分月度走势** | 无 | 同上 |
| **车间 × 月份 KPI 热力矩阵**（指标切换） | 无 | 规格 P0、验收第 1 条缺口 |
| 全厂合计行与点检 `＊` 脚注说明 | 无表尾合计行 | 全厂口径不易核对 |
| 点检 KPI 卡文案「点检达标车间 x/y 个」 | 现为「点检均值」分 | 与原型叙事不一致（算法部分在领域层有 `chkOK/chkTotal`，未展示） |

## 4. 车间总览（`dash`）

### 4.1 一致

- 车间横幅：名称、负责人、CE、色条。
- 核心 KPI：首件合格率、5 分钟反馈率、15 分钟介入率、投诉结案率、点检最近一次、终检批次不良率。
- 预警列表（未结案投诉、首件 NG 等）。
- 快捷按钮跳转首件 / FQC / 投诉（原型为更多入口与卡片跳转）。

### 4.2 不一致

| 原型区块 | 现系统状态 | 影响 |
|---|---|---|
| **首件异常处置机制**（5 步强制流程图文） | 无 | 规格 5.3、验收第 5 条 |
| **终检不良 TOP**、**绩效排名 TOP7**（条形图） | 无 | 车间例会「一眼看清」能力下降 |
| 点检达标池、按时结案率等多 KPI | 未展示 | 与原型车间总览信息密度不符 |
| 预警条目的 **跳转动作**（`data-jump` 直达子模块） | 仅文案展示 | 交互闭环弱 |
| 投诉 / 点检等更多快捷入口 | 仅 3 个按钮 | 可接受缩小，但与原型不一致 |

## 5. 首件 / 巡检（`fa`）

### 5.1 一致

- 按当前车间过滤台账。
- 注塑毛边：无数据时的说明（`el-alert` ↔ 原型脚注）。
- **NG 确认**列：按阶段计算角色（`faNgConfirmLabel`）。
- 判定 **NG/OK** 可改并持久化（局部编辑）。

### 5.2 不一致

| 原型能力 | 现系统状态 | 影响 |
|---|---|---|
| 顶栏 **6 项 KPI**（批次、NG 率、反馈/介入率、未关闭、超时） | 无 | 录入页缺少即时反馈 |
| **标准 / 规范自动查询**（左栏索引、类型筛选） | 无 | 规格 P0「标准索引」 |
| **记录录入**全字段可编辑表（规格、实测、对策、签署等） | 只读列为主，仅判定下拉 | 规格 5.8 大幅未落地 |
| **各车间 NG 率**、**反馈时长分布** 图 | 无 | 分析视图缺失 |
| **重点零件 100394-003** 追踪卡与结论文案 | 无 | 规格 5.3、验收第 6 条 |
| **NG 判定责任分工**说明卡 | 无 | 流程可见性不足 |
| 阶段筛选（全部 / TH RUN / 量产等） | 无 | 与原型筛选不一致 |
| Ctrl+Z 撤销、区域粘贴、Tab 移格 | 无 | 规格 5.8 |

## 14. 附录：ego-browser 区块标题快照（注塑车间上下文）

**原型（节选）**

- 总看板：热力矩阵、投诉走势、点检走势、关注事项
- 车间总览：首件异常处置机制、终检不良 TOP、绩效 TOP7
- 首件：标准查询、100394-003、NG 率图、反馈分布
- FQC：月度检验量、柏拉图图、检验员分析、结论与改善
- 投诉：趋势、根因分类、来源分布
- 点检：排名 spark、趋势图、项明细、30 日色块
- 培训 / 绩效：多 Tab 与构成图
- 数据：口径说明、数据源文件

**现系统（节选）**

- 总看板：KPI 六卡 + 对比表 + 异常关注（无图、无矩阵）
- 车间总览：6 KPI + 预警 + 3 快捷按钮
- 首件：单表 + 毛边 alert
- FQC：3 KPI + 两张简表
- 投诉 / 培训 / 绩效 / 点检：各 1～2 张简表
- 数据：JSON 三按钮 + 计数
