## 后端 API

接口前缀 **`/api`**。JSON 字段 **camelCase**，信封遵循 dev-standards。**质量台账仍保存在浏览器 localStorage**；用户确认「共享盘同步」后，源表数组由 API 解析结果覆盖，培训 `trn` / `exam` / `skill` 与培训资料 `mat` 保留本机内容。

### 登录与会话

| 方法 | 路径 | 说明 |
|---|---|---|
| `POST` | `/api/auth/login` | body `{ phone, password }`；成功写 IPQC 会话 Cookie，`data` 为当前用户 |
| `GET` | `/api/auth/me` | 当前本地用户；无会话 401 |
| `POST` | `/api/auth/logout` | `{ ok: true }`，清除会话 |
| `GET` | `/api/auth/data-hub/link` | 当前用户是否已保存 data-hub 刷新令牌 `{ linked, dataHubUserId }` |
| `POST` | `/api/auth/data-hub/link/start` | 返回 `{ authorizeUrl }`，用于共享盘授权（须已登录 IPQC） |
| `POST` | `/api/auth/data-hub/link/callback` | body 含 OAuth `code`/`state`；保存刷新令牌密文 |
| `POST` | `/api/auth/data-hub/link/unlink` | 删除本用户 data-hub 刷新令牌密文，`{ linked: false }` |

当前用户 `data` 字段：`id`、`phone`、`displayName`、`role`、`dataHubUserId`。

### 共享盘台账同步

| 方法 | 路径 | 说明 |
|---|---|---|
| `GET` | `/api/ledger-sync/shares` | 当前用户在 data-hub 的绑定列表 `{ list, total, page, pageSize }` |
| `GET` | `/api/ledger-sync/shares/:shareId/entries?path=` | 列出共享盘子项 `{ list: [{ name, path, kind: 'directory' \| 'file' }] }`，供懒加载选择器 |
| `POST` | `/api/ledger-sync/preview` | body `{ shareId, selectedEntries, excludedPaths? }`（`selectedEntries` 必选，空选择 400）；返回 `{ files, summary, issues, counts? }`，有阻止项时仍 200 |
| `POST` | `/api/ledger-sync` | body 同上，并带 `{ previewFiles }`；成功 `data` 含 `{ files, counts, snapshot, checkScores? }`。旧字段 `rootPaths`/`rootPath` 仅兼容入口 |

同步失败时：`400` + `bad_request`（缺文件、列不匹配等）；`404` + `not_found`（找不到可用的共享盘）；`401` + `unauthorized`（`message`：data-hub 授权已失效，请重新登录）。

## 错误与提示

| HTTP / code | `msg` | `message`（示例） |
|---|---|---|
| 400 | `bad_request` | 参数或校验失败 |
| 401 | `unauthorized` | 请先登录 / 登录状态已失效 |
| 409 | `conflict` | 手机号重复，请管理员处理 |
| 500 | `internal_error` | 服务器繁忙，请稍后重试 |
