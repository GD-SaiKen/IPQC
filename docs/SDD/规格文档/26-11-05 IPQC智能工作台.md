## 1. 范围

### 本期做什么

建设品质保证部 **IPQC 智能工作台**：以「总看板 → 车间子工作台 → 业务模块」三层导航，把首件巡检、终检 FQC、投诉闭环、过程点检、培训技能、工作绩效串成统一口径的可视化与台账操作界面。

责任区（车间）固定为 6 个：`注塑`、`注塑毛边`、`压铸`、`五金`、`涂装`、`印刷`；顶栏车间筛选与子工作台进入方式与原型一致。

### 明确不做什么

- 不建设企业账号 / RBAC、不接入 AD / SSO（原型为单机浏览器使用，无登录）。
- 不实现服务端持久化、多用户实时协同、消息推送 / 企业微信（NG 5/15 分钟机制在界面层展示与统计，不作真实告警投递）。
- 不第一期对接 MES / ERP / 文控系统 API；标准文档索引可先静态或本机索引，不做在线预览 CAD 全功能编辑器。
- 不改变既有 Excel 源表目录结构与命名约定（导入逻辑另期 SDD）。
- 不修改 `.github/` 自动开发流水线（见 [26-11-06 组织级自动开发流水线](./26-11-06%20组织级自动开发流水线.md)）。

## 2. 目标行为（场景）

| 场景 | 现在（无系统 / 分散台账） | 改后（工作台） |
|---|---|---|
| 管理层看全厂 | 各车间表格分散，月度对比需手工汇总 | **总看板**按月份（全年或 1–10 月）展示 6 车间六项指标矩阵与走势、异常关注 |
| IPQC 进某车间 | 打开多份 Excel / 文件夹 | 点车间进入**子工作台**，导航收敛为：总览、首件巡检、FQC、投诉、点检、培训、绩效 |
| 首件 NG | 口头 / 群通知，时效难统计 | 记录表支持 NG 判定；KPI 统计 **5 分钟反馈率、15 分钟介入率**；展示强制处置流程 |
| 终检不良 | 各车间台账格式不一 | 多台账合并视图 + 单本台账 drill-down；批次不良率、帕累托、NG 明细可编辑 |
| 投诉 | 阶段与结案分散 | 受理 → 临时对策 → 原因 → 永久对策 → 结案验证；时限与责任人可追踪 |
| 点检排名 | 各车间表不一 | 统一评分制（满分 140、目标 100）；**注塑毛边**适用项分值规则单独说明，避免与全厂均值误解 |
| 培训绩效 | 资料与考核分散 | 资料库 + 实施记录 + 考核 + 技能矩阵；绩效四维加减分与排名 |
| 数据备份 | 仅存本机 Excel | **数据与设置**：localStorage（或工程态 IDB）自动保存；JSON 导入导出；表格 CSV 导出；打印 / PDF |

## 3. 信息架构与导航

### 3.1 视图（路由键建议）

| 键 | 名称 | 说明 |
|---|---|---|
| `board` | 总看板 | 仅「全部车间」口径；进入车间子工作台时切走 |
| `dash` | 车间总览 | 子工作台首页 KPI + 异常条 + 快捷跳转 |
| `fa` | 首件 / 巡检检验 | 标准索引 + 录入表 + NG 机制 |
| `fqc` | 终检报告 FQC | 多台账、月度、帕累托、NG 明细 |
| `cmp` | 零件投诉闭环 | 全流程状态与时限 |
| `chk` | 关键点检排名 | 日打分、月汇总、排名（子工作台内可限定当前车间） |
| `trn` | 培训与技能 | 资料 + 记录 + 矩阵 |
| `perf` | 工作绩效 | 个人得分与排名 |
| `data` | 数据与设置 | 备份、恢复、口径说明 |

### 3.2 车间子工作台

- 从总看板侧栏或顶栏 chip **进入**某车间后：`UI.ws` 锁定为该车间；侧栏展示子集导航 + 切换车间 / 返回总看板。
- 子工作台横幅展示：车间名、负责人、CE；文案声明**指标口径与总看板一致**。
- 点检页在子工作台内：排名与趋势可为**全厂口径**（横向比较），明细与日打分为**当前车间**（与原型一致）。

### 3.3 全局壳层

- 左侧固定导航 + 顶栏标题（路径面包屑）+ 车间筛选 chips + 内容区滚动。
- Hash 路由（`#board`、`#fa` 等）可深链；切到 `board` 时车间重置为「全部」。

## 4. 业务规则（必须一致）

### 4.1 首件 / 巡检（`fa`）

- **注塑 / 压铸 / 五金**共用「首巡检报告」表结构：**S**＝首件、**X**＝巡检。
- **印刷**首件与终检共用一份表：**首件区域** + **FQC 区域**。
- 产品阶段：`新产品 TH RUN 样品`、`销售员样品`、`量产`。
- NG 后：**5 分钟内反馈**、**15 分钟内介入**、**无对策不得生产**、复检结案——总览 KPI 与流程卡须体现。
- **NG 确认角色**（「NG 确认」列自动标注，改判定或阶段即时刷新）：
  - 新产品阶段（TH RUN + 销售员样品）：**开发工程师 + QE 工程师**；
  - 量产阶段：**工艺工程师**；
  - 判定 OK 时显示「—」。

### 4.2 终检 FQC（`fqc`）

- 车间与台账映射：`注塑`、`注塑毛边`、`压铸`、`五金`、`涂装`、`印刷` 各可对应一本或多本台账；「全部」为合并口径。
- 支持按月的批次、抽样、NG、不良率；帕累托主因；高不良（如 ≥20%）在总览告警。
- 全厂 / 单本台账不良率超阈值（原型 3%）时置顶告警。

### 4.3 投诉（`cmp`）

- 阶段：受理 → 临时对策 → 原因分析 → 永久对策 → 结案验证。
- KPI：结案率、按时结案、按时回复；未结案在总览异常区展示。

### 4.4 点检（`chk`）

- 全表满分 **140**，目标 **100**；6 个责任区**同一评分制**。
- **注塑毛边**：适用项 1–9 月合计 **40** 分、10 月起 **60** 分（非执行退步）；总看板须用脚注 / tooltip 说明全厂均值含毛边与剔除毛边差异。

### 4.5 培训（`trn`）与绩效（`perf`）

- 培训：资料库 → 实施记录 → 考核 → 技能矩阵（多能工 / 轮岗）。
- 绩效：满分 100，维度含准确率、准时率、纪律、团队协作；支持加减分与排名。

### 4.6 数据（`data`）

- 编辑：**表格单元格内联编辑**，失焦或选择变更后自动保存。
- 撤销：**Ctrl/Cmd+Z** 仅撤销当前页最近一次单元格编辑（与原型一致）。
- 键盘：**Tab / Shift+Tab / Enter** 在可编辑单元格间导航（类 Excel）。
- 中文输入法：组词期间不触发 live 刷新，避免打断输入。
- Live 刷新：改数字后 KPI / 图表 / 结论区更新，**表格 DOM 尽量保持**（滚动位置、焦点）。
- 导出：各表 **CSV**；全局 **JSON** 导入导出；**恢复原始种子数据**须二次确认。
- 打印：隐藏侧栏 / 多余控件，适合纸质看板（`board` 模式可选）。

## 5. 交互 / 权限 / 边界

| 项 | 约定 |
|---|---|
| 权限 | 无登录；所有用户等同编辑权限（与企业版分权另期） |
| 只读 | 无只读模式；导入 JSON 覆盖全库前须提示 |
| 加载 | 首屏从本地存储读取；无数据时用内置种子数据初始化 |
| 归档 | 无服务端归档；依赖 JSON 备份 |
| 离线 | 原型态纯前端；工程实现可 PWA，仍不承诺多端实时同步 |
| 标准文档 | 左侧索引可搜 Excel / Word / CAD 文件名；打开方式：下载或浏览器可预览类型，CAD 仅链接 |

## 7. 验收（可观察结果）

1. 打开应用默认进入总看板；切换 1–10 月 / 全年，矩阵六项指标与原型口径一致（允许数据来自同一套种子或导入 JSON）。
2. 进入「注塑车间」子工作台后，侧栏仅显示子集模块；总览 KPI 与总看板同车间同月可对上。
3. 首件表：改一条为 NG，总览 **5 分钟 / 15 分钟** 相关 KPI 与 NG 行样式、确认角色列同步变化。
4. FQC：切车间 / 台账来源，帕累托与 NG 明细条数随筛选变化；导出 CSV 含当前筛选结果。
5. 投诉：未结案记录在总览异常区出现；结案后从异常区消失且结案率更新。
6. 点检：毛边车间得分低于 140 满分项时，总看板脚注说明「适用项少」逻辑可见。
7. 数据页：导出 JSON → 清空本地 → 导入 JSON 后数据与编辑前一致。
8. Ctrl+Z 撤销单元格后 toast 提示，且仅影响当前视图所在表。
9. 打印预览无侧栏与顶栏筛选，主内容可读。

验收以本期规格 + [实施计划](../实施计划/26-11-05%20IPQC智能工作台%20实现计划.md) 为准；E2E 用例在实现阶段再固化 `data-testid`。
