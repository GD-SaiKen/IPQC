# 台账文件绑定 实现计划

> **面向实现者：** 按下列顺序改。先补绑定与「单文件失败不拖垮其余文件」的测试，再改服务与页面。  
> **规格：** [台账文件绑定](../规格文档/26-11-21%20台账文件绑定.md)  
> **目标：** 核对与同步只读「角色 + 路径 + 列模板」，不再按文件名扫目录。  
> **架构：** 绑定存在现有 `ledger_sync_config.selected_entries` JSON 里（文件项带 `role`、`template`），不新增表。列模板由角色决定。解析按文件捕获缺列，失败项标无效，成功项仍入库。  
> **技术栈：** NestJS、Vue 3、Vitest

## 文件

| 路径 | 职责 |
|---|---|
| `apps/api/modules/ledger-sync/ledger-bindings.ts` | 角色到列模板、校验绑定、重复角色 |
| `apps/api/modules/ledger-sync/map-workbook.ts` | 单文件解析失败记入 `failures`，其余继续 |
| `apps/api/modules/ledger-sync/ledger-sync.service.ts` | 预览、保存、立即同步、定时同步只走绑定 |
| `apps/web/src/views/data/ledger-bindings.ts` | 页面用的角色与模板文案 |
| `apps/web/src/views/data/index.vue` | 只勾选文件、为文件选角色、保存绑定 |

## 任务

- [ ] 绑定校验：目录、缺角色、模板与角色不一致、同一角色两条，均不能当作有效绑定
- [ ] 映射：点检排名缺列时该文件进入 `failures`，另一份已成功的投诉表仍出现在快照里
- [ ] 预览与 `POST /ledger-sync/config`：只接受带角色的文件；目录返回 400
- [ ] 页面：文件树 `check-strictly`，勾选目录立即取消并提示；每个文件下拉角色，模板只读；摘要改为已绑定 / 已解析 / 解析失败
- [ ] 已保存的旧目录配置不能直接核对，需重新绑文件

## 不改

- data-hub、看板计算公式、培训四张表
- 不新增散页首件模板
