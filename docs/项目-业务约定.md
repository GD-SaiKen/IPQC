# IPQC 项目 · 业务约定

与 Cursor skill **dev-standards** 中的前后端信封互补；**路由与领域枚举以本文 + 本期 SDD 为准**。

## 车间（责任区）

| 键 `workshopKey` | 显示名 |
|---|---|
| `注塑` | 注塑车间 |
| `注塑毛边` | 注塑毛边车间 |
| `压铸` | 压铸车间 |
| `五金` | 五金车间 |
| `涂装` | 涂装车间 |
| `印刷` | 印刷车间 |

顶栏「全部」表示全厂口径，键为 `全部`（仅筛选 UI，非持久实体）。

## 前端路由（规划，第一期）

| path | 视图键 | 标题 |
|---|---|---|
| `/board` | board | 总看板 |
| `/dash` | dash | 车间总览 |
| `/fa` | fa | 首件巡检检验 |
| `/fqc` | fqc | 终检报告 FQC |
| `/cmp` | cmp | 零件投诉闭环 |
| `/chk` | chk | 关键点检排名 |
| `/trn` | trn | 培训与技能 |
| `/perf` | perf | 工作绩效 |
| `/data` | data | 数据与设置 |

子工作台状态：`workshopKey` 存于 query（如 `?ws=注塑`）或 store，与 SDD 规格一致。

## 后端 API（第一期）

无。本地 `localStorage` / IndexedDB；后续 REST 资源前缀建议 `/ipqc/…`，信封遵循 dev-standards。

## 错误与提示（预留）

| HTTP / code | `msg` | `message`（示例） |
|---|---|---|
| 400 | `bad_request` | 参数或校验失败 |
| 500 | `internal_error` | 服务器繁忙，请稍后重试 |
