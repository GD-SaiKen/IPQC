## 后端 API（统一身份登录）

接口前缀 **`/api/v1`**。JSON 字段 **camelCase**，信封遵循 dev-standards。**质量台账仍保存在浏览器 localStorage**，本期接口只负责登录与会话。

| 方法 | 路径 | 说明 |
|---|---|---|
| `POST` | `/api/v1/auth/data-hub/start` | 写 OAuth `state` Cookie，返回 `{ authorizeUrl }` |
| `POST` | `/api/v1/auth/data-hub/callback` | 换票认人，写 IPQC 会话 Cookie；成功 `data` 为当前用户 |
| `GET` | `/api/v1/auth/me` | 当前本地用户；无会话 401 |
| `POST` | `/api/v1/auth/logout` | `{ ok: true }`，清除会话 |

当前用户 `data` 字段：`id`、`phone`、`displayName`、`role`、`dataHubUserId`。

## 错误与提示

| HTTP / code | `msg` | `message`（示例） |
|---|---|---|
| 400 | `bad_request` | 参数或校验失败 |
| 401 | `unauthorized` | 请先登录 / 登录状态已失效 |
| 409 | `conflict` | 手机号重复，请管理员处理 |
| 500 | `internal_error` | 服务器繁忙，请稍后重试 |
