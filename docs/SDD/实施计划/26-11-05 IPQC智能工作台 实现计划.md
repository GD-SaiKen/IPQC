## 实施偏差与说明（2026-11-10）

| 计划项 | 实际实现 | 原因 / 影响 |
|---|---|---|
| 种子抽取到单个 `fixtures/ipqc-seed.json` | `scripts/extract-prototype-seed.mjs` 输出 `real.json`、`fqcs.json`、`check-items.json`、`std-index.json`、`skills.json`、`perf-rules.json` 等分文件 | 分文件便于领域层按需导入与 code split，数据口径不变 |
| 全局撤销栈 | 每张可编辑表独立撤销栈（`useEditHistory(tableId)`），Ctrl/Cmd+Z 只回退当前激活表 | 与规格 5.8「当前表最近一次编辑」一致，避免跨表回退 |
| 图表能力 | 自建 SVG 组件（柱、折线、柱线组合、柏拉图、横向条、环形、热力矩阵、sparkline、日色块），未引入图表库 | 遵守「不引图表库」约束，离线可用 |
| 标准索引打开方式 | 图片尝试浏览器预览；Excel / Word / CAD 复制本机路径 | 浏览器安全策略禁止直接打开 `file://` 文档 |
| 侧栏模块记录数角标 | 未注入 | 原型有、规格未要求；不影响 §7 验收 |
| 浏览器 E2E | 未新增 Playwright/Cypress | 仓库原无 E2E 工具链；本期以 `lint` + 领域单测 + `build` 与手工路径核对 |
| `lint` 脚本 | `vue-tsc -b`（原 `vue-tsc -b --noEmit` 触发 TS6310） | 修复仓库既有门禁故障；`tsconfig.node.json` 改为仅声明输出到 `node_modules/.tmp` |

验证命令与结果：

- `pnpm lint`：通过（无错误）。
- `pnpm test`：9 个测试文件 / 64 条用例全通过。
- `pnpm build`：通过（Vite 构建成功；仅有 chunk 体积提示）。
